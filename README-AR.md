# MYGRAM 2.7 — إصلاحات واجهة وخدمات (حزمة اختبار)

## ترتيب التنفيذ
1. خذ نسخة احتياطية من Supabase والمستودع.
2. في Supabase > SQL Editor شغّل ملف `MYGRAM-2.7-setup.sql` مرة واحدة. الملف إضافي ويترك جدول `public.messages` القديم كما هو، لكنه يعدّل قيد المنشورات للسماح بمنشور مرفق بلا نص، ويضيف جداول الخدمات والتفاعلات والتعليقات.
3. بعد نجاح SQL، ارفع ملفات الواجهة الموجودة في هذا ZIP إلى جذر مستودع GitHub مع استبدال الملفات ذات الأسماء المطابقة فقط. لا تحذف الملفات الأخرى.
4. انتظر نشر GitHub Pages، ثم اختبر كل وظيفة.

## ما جرى التحقق منه محليًا
- سلامة ZIP.
- صياغة JavaScript.
- وجود ملفات JavaScript المحلية التي تشير إليها صفحات HTML.
- تحديث الواجهة لإظهار أزرار الإعجاب والتعليقات للمنشورات.
- تحديث اللون الرئيسي إلى الأزرق مع تدرج دافئ.

## حدود مهمة
لم يُنفّذ SQL في مشروع Supabase الخاص بك ولم تُختبر الواجهة بعد رفعها على حسابك؛ لا يمكن ضمان أن كل الوظائف تعمل قبل ذلك. الحزمة لا تنفذ بثًا حيًا حقيقيًا ولا استيراد دفتر الهاتف، ولا تجعل المحادثات قائمة تلقائية بجهات الاتصال؛ هذه تحتاج دمجًا منفصلًا وصلاحيات وموافقة المستخدم.
لا تضع مفاتيح service_role أو أي أسرار في ملفات الواجهة.
