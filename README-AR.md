# MYGRAM 2.6 — حزمة تحديث منظمة

## قبل النشر
هذه الحزمة تجمع ملفات الواجهة الحالية وتضم تصحيحًا لخطأ RLS في ملف SQL: تفعيل الحماية على `direct_messages` بدل جدول `messages` القديم. لا تحذف الحزمة جدول الرسائل القديم ولا تنفذ SQL تلقائيًا.

**حدود التحقق:** تم فحص سلامة ملف ZIP وصياغة JavaScript. هذا لا يثبت أن كل وظيفة تعمل على الموقع الحي أو أن مخطط Supabase مطابق تمامًا. لا يمكن وصف جميع الميزات المطلوبة بأنها مكتملة في هذا الإصدار.

## الملفات
ملفات HTML وJavaScript وCSS وأيقونات الواجهة موجودة مباشرة في جذر الحزمة لتسهيل رفعها إلى جذر المستودع. ملف SQL موجود داخل `sql/`.

## تعليمات نشر آمنة
1. نزّل نسخة احتياطية من المستودع الحالي قبل استبدال الملفات.
2. ارفع ملفات الواجهة إلى جذر المستودع مع الحفاظ على أي ملفات موجودة ليست ضمن هذه الحزمة.
3. ارفع ملف `sql/phase2.5-social-services.sql` إلى المستودع فقط كملف؛ لا تشغّله تلقائيًا على Supabase.
4. قبل تشغيل SQL، راجع مخطط قاعدة البيانات الحالي وخذ نسخة احتياطية. لا تشغّل الملف إذا ظهرت أخطاء أو اختلافات في الجداول.
5. اختبر تسجيل الدخول، إنشاء المنشور، الملف الشخصي، رفع الصور، الحالات والرسائل بحسابين منفصلين.

## ميزات لم يثبت اكتمالها في هذا الإصدار
- تفاعلات المنشورات والتعليقات وردود التعليقات.
- حزم الملصقات والإشعارات الكاملة.
- استيراد جهات الاتصال.
- بث فيديو حي حقيقي؛ بطاقة/سجل جلسة البث ليست خدمة بث فعلية.
- إشعارات الدفع والمكالمات ومزامنة المحادثات اللحظية.

## الأمان
- لا تضع مفاتيح `service_role` أو الأسرار داخل ملفات الواجهة.
- يستخدم هذا الإصدار جدول `direct_messages` للرسائل الجديدة، ويترك جدول `messages` القديم دون تعديل.
