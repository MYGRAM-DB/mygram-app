# MYGRAM — المرحلة 2.2: فصل الأصدقاء والملف الشخصي

## ما الجديد؟
- صفحة مستقلة للأصدقاء: `people.html` للبحث وطلبات الصداقة فقط.
- صفحة مستقلة للملف الشخصي: `profile.html` لتعديل الاسم واسم المستخدم والنبذة ورابط الصورة.
- قائمة حساب صغيرة بدل زر تسجيل الخروج الكبير؛ تسجيل الخروج موجود أسفل القائمة.
- فحص أولي لتوفر اسم المستخدم مع تنبيه عند استخدامه. الحفظ في قاعدة البيانات يبقى المرجع النهائي للتأكد من عدم التكرار.
- شريط تنقل موحّد للموبايل.

## التثبيت من الهاتف
1. افتح مستودع GitHub `MYGRAM-DB/mygram-app` ثم Upload files.
2. فك ضغط هذا الملف على جهازك أولاً، ثم ارفع الملفات الموجودة داخله إلى جذر المستودع، وليس ملف ZIP نفسه.
3. استبدل الملفات ذات الأسماء المتطابقة وأضف الملفات الجديدة: `profile.html` و`profile.js` و`account-menu.js` ومجلد `icons`.
4. ارفع أيضاً `people.js` و`home.html` و`people.html` و`styles.css` و`config.js` وملفات SVG الموجودة. لا تحذف `index.html` أو `auth.js` أو `home.js` أو ملفات SQL.
5. اضغط Commit changes وانتظر دقيقة أو دقيقتين.
6. جرّب: `https://mygram-db.github.io/mygram-app/home.html` ثم افتح `people.html` و`profile.html`.

## مهم
- الحزمة لا تغيّر قاعدة بيانات Supabase ولا تحتاج تشغيل SQL جديد.
- حقل الصورة حالياً يقبل رابط صورة فقط؛ رفع الصور مباشرة من الهاتف/الكاميرا/Drive يحتاج إعداد Storage وسيأتي في مرحلة لاحقة.
- خيار الإعدادات يظهر كقسم تمهيدي فقط حالياً.
- احتفظ بنسخة من الملفات الحالية قبل الاستبدال. لا ترفع أي مفاتيح سرية مثل service_role.
