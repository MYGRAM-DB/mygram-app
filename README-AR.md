# MYGRAM 2.8 — إصدار إصلاح التكامل

تطبيق ويب ثابت على GitHub Pages مع Supabase (مصادقة، قاعدة بيانات، تخزين).

## ما تم إصلاحه
- `config.js` كان يعرّف `SUPABASE_URL` فقط بينما بقية الملفات تقرأ `supabaseUrl` و`supabaseKey` و`homeUrl` و`loginUrl` (قيم غير معرّفة فلا يبدأ الاتصال). أصبحت الصيغتان معرّفتين.
- `app.js` كان يستعلم عن جدول `profiles` بينما بقية الصفحات تستخدم `users`؛ تم التوحيد على `users`.
- توحيد اسم الـ bucket على `mygram-media`.
- لم يكن في المستودع أي ملف SQL؛ أُضيف `supabase/migrations/20261024000000_mygram_core.sql`.
- أُضيف `.nojekyll` وملف الفحص `tests/check.js` وworkflow يشغّله.

## التثبيت
1. **افحص البيانات القديمة أولاً** في Supabase SQL Editor: `select count(*) from public.users; select count(*) from public.messages;` وتأكد أن `users.id` من نوع `uuid`.
2. شغّل ملف الهجرة `supabase/migrations/20261024000000_mygram_core.sql` (آمن للتكرار ولا يحذف شيئاً).
3. Authentication ← URL Configuration: اجعل Site URL هو `https://mygram-db.github.io/mygram-app/` وأضفه مع `/home.html` إلى Redirect URLs.
4. ارفع محتويات مجلد `app/` إلى جذر المستودع (وليس ملف ZIP).
5. شغّل `node tests/check.js`.

## الحالة الحالية بصدق

- واجهة الصفحة الرئيسية، MYGRAM Messenger، WHATSMYGRAM، وأدوات الدردشة المشتركة واجتماعات MYGRAM موجودة في فرع التطوير. فرع التطوير وPR رقم 30 غير مدموجين في main؛ لذلك لم تُنشر هذه الواجهات إلى GitHub Pages بعد.
- قاعدة Supabase تحتوي على مخطط حضور المستخدم والصوت، محادثات WHATSMYGRAM المستقلة، وأدوات الدردشة (مواضيع، تثبيت، محفوظات شخصية، استطلاعات)، ومخطط اجتماعات مع حضور ودردشة وسجل نقل الرئاسة ونصوص ومحاضر لكل مشارك. شُغّلت الهجرات الإضافية على المشروع مع تفعيل RLS على الجداول الجديدة، ولم تُحذف رسائل أو حسابات.
- دوال Edge الخاصة بـ meetings-token وmeeting-ai-minutes نُشرت مع التحقق من JWT. الفيديو يتطلب أسرار LiveKit، وتوليد المحاضر الذكية يتطلب مزوّد ذكاء اصطناعي مضبوطاً في أسرار Supabase. لا توجد أسرار خدمة داخل كود المتصفح أو المستودع.
- ميزة الاجتماعات الحالية تدعم إنشاء الغرفة، دعوات برمز، حضوراً حتى 31 مشاركاً إجمالاً، نقل الرئيس، دردشة نصية، موافقات منفصلة قبل حفظ النص، ومحاضر شخصية متعددة اللغات مع تصدير عبر نافذة الطباعة إلى PDF. لا ندّعي أن اتصال الفيديو أو توليد AI يعمل قبل ضبط أسرارهما واختبارهما فعلياً.
- تحويل الكلام إلى نص في واجهة التجربة يعتمد على دعم المتصفح ويستمع إلى ميكروفون الجهاز المحلي فقط؛ لا يمثل نظاماً كاملاً لتسجيل كل مشارك أو تمييز المتحدثين في مكالمة جماعية. كذلك تصدير PDF يتم من المتصفح ولا يُرسل تلقائياً بالبريد.
- أدوات الدردشة المشتركة الموجودة في الواجهة: البحث، المواضيع في المحادثات الجماعية، تثبيت الرسائل وفق الصلاحيات، حفظ الرسائل الشخصية، والاستطلاعات. طبقة المخطط تشمل أيضاً أساساً للأدوار والقنوات والمنتديات، لكن تجربة إنشاء/اكتشاف القنوات العامة، البوتات وMini Apps، المحادثات السرية بتشفير طرف لطرف، والترجمة الفورية الكاملة ليست مكتملة بعد.
- 60 لغة و205 بلدان/مناطق مع رموز اتصال موجودة في مسار التوطين، لكن 47 نصاً أساسياً لكل لغة لا تعني ترجمة يدوية كاملة لكل شاشة وميزة.

## استكشاف الأخطاء
- فشل الرفع: لم تُشغَّل الهجرة (الـ bucket والسياسات غير موجودة).
- الدخول ينجح لكن الملف فارغ: شغّل قسم backfill من الهجرة.
- رابط تأكيد البريد يفتح عنواناً خاطئاً: صحّح URL Configuration.
