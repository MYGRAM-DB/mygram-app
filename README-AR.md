# MYGRAM — المرحلة 2.3 ❤️

## ما الجديد؟
- رفع صورة الملف الشخصي مباشرةً من المعرض/الملفات، مع معاينة قبل الحفظ (حتى 5 MB).
- إرفاق صورة أو فيديو بالمنشور من الهاتف (حتى 50 MB).
- عرض المرفقات داخل المنشورات، مع بقاء المنشورات القديمة ظاهرة.
- الحفاظ على الصفحات المنفصلة وقائمة الحساب.

## مهم جداً قبل الاختبار
1. ارفع كل الملفات الموجودة داخل الحزمة إلى جذر مستودع GitHub، واستبدل الملفات المتطابقة، وأضف الملفات الجديدة. لا تحذف ملفات `index.html` أو `auth.js` أو ملفات SQL القديمة.
2. في Supabase افتح SQL Editor، وافتح الملف `phase2.3-storage.sql` من هذه الحزمة، وانسخ محتواه إلى SQL Editor ثم اضغط Run مرة واحدة. هذا ينشئ bucket `mygram-media` وسياسات الوصول المطلوبة ويضيف حقول المرفقات إلى `posts`.
3. لا تضع أي مفتاح سري أو `service_role` في الموقع. الإعداد الحالي يستخدم المفتاح العام publishable.
4. انتظر تحديث GitHub Pages، ثم جرّب حفظ صورة الملف الشخصي، وبعدها منشور صورة. الفيديوهات تعتمد على صيغ المتصفح المقبولة (MP4/WebM/QuickTime).

## الملفات
ارفع ملفات HTML/JS/CSS و`config.js` وملفات `icons/` و`phase2.3-storage.sql`. لا ترفع ملف ZIP نفسه.

## ملاحظة
الصور في هذا الإصدار مخزّنة في bucket عام لتظهر داخل المنشورات؛ أي شخص يملك رابط الملف قد يتمكن من مشاهدته. لا ترفع صوراً خاصة أو حساسة.
