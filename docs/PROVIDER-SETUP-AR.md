# إعداد البريد والهاتف والمكالمات في MYGRAM بأقل تكلفة

هذه خطوات عملية. لا تضع أي كلمة مرور أو مفتاح API في المستودع أو في ملفات JavaScript التي تصل للمتصفح.

## 1. تفعيل البريد الإلكتروني مجاناً عبر Brevo

تعلن Brevo عن خطة SMTP مجانية تصل إلى 300 رسالة يومياً. يوجد بديل هو Resend الذي يعلن عن 3,000 رسالة شهرياً وبحد 100 رسالة يومياً. قد تتغير الحدود وشروط التفعيل، لذا راجع صفحات الأسعار الرسمية.

- [Brevo SMTP المجاني](https://www.brevo.com/free-smtp-server/)
- [Resend والأسعار](https://resend.com/pricing)
- [دليل Supabase الرسمي لإعداد SMTP](https://supabase.com/docs/guides/auth/auth-smtp)

### الخطوات

1. أنشئ حساباً مجانياً في Brevo.
2. أضف نطاقاً تملكه أنت، ثم أضف سجلات DNS التي يطلبها Brevo لإثبات الملكية وتفعيل SPF وDKIM. يفضّل إعداد DMARC أيضاً.
3. من Brevo افتح إعدادات SMTP & API وأنشئ SMTP key. احتفظ به سرياً.
4. افتح لوحة Supabase للمشروع ثم **Authentication → SMTP Settings**، وفعّل SMTP مخصصاً وأدخل:
   - Host: `smtp-relay.brevo.com`
   - Port: `587` مع STARTTLS
   - Username: قيمة SMTP login التي يعرضها Brevo
   - Password: مفتاح SMTP الذي أنشأته، وليس كلمة مرور حساب Brevo
   - Sender name: `MYGRAM`
   - Sender email: بريد تابع للنطاق الذي تم التحقق منه
5. افتح **Authentication → URL Configuration** واضبط Site URL على `https://mygram-db.github.io/mygram-app/` وأضف روابط العودة الدقيقة المستخدمة في الموقع إلى قائمة Redirect URLs.
6. راجع قوالب تأكيد البريد واستعادة كلمة المرور واحفظها.
7. اختبر التسجيل واستعادة كلمة المرور ببريد حقيقي خارج فريق Supabase. افحص صندوق الوارد والرسائل غير المرغوب فيها وسجل التسليم لدى Brevo.

لن أستطيع إتمام إدخال كلمة مرور SMTP من دون دخولك إلى لوحة المزود، ولا ينبغي إرسالها في المحادثة. بعد إدخالها هناك، يمكن اختبار الإرسال من التطبيق.

## 2. تسجيل الهاتف برمز SMS

Supabase يدعم تسجيل الهاتف، لكن إرسال SMS يحتاج مزوداً خارجياً. لا يوجد مزود أستطيع أن أضمن أنه يرسل SMS حقيقية إلى 205 دولة مجاناً إلى الأبد. الأرصدة التجريبية غالباً محدودة بالوقت أو البلدان أو الأرقام الموثقة، ورسوم شركات الاتصالات مستمرة.

- [دليل Supabase الرسمي للهاتف وSMS](https://supabase.com/docs/guides/auth/phone-login)
- [أسعار Twilio حسب البلد](https://www.twilio.com/sms/pricing)
- [أسعار Vonage](https://www.vonage.com/communications-apis/sms/pricing/)

### الخطوات

1. اختر مزوداً وافتح حساباً معه، وتحقق من سعر الرسالة وقواعد المرسل في كل دولة مستهدفة.
2. في Supabase افتح **Authentication → Providers → Phone** وفعّل تسجيل الهاتف.
3. اختر مزود SMS المدعوم في لوحة مشروعك وأدخل بياناته السرية في لوحة Supabase فقط.
4. اضبط حدود إرسال الرموز ووسيلة منع الإساءة/CAPTCHA.
5. اختبر إرسال رمز فعلي إلى أرقام تملكها وبموافقة أصحابها في كل دولة مستهدفة، ثم اختبر الرمز الصحيح والخاطئ والمنتهي.
6. أبقِ البريد الإلكتروني متاحاً كطريقة مجانية بديلة إلى أن تنجح اختبارات SMS الحقيقية.

لا تستخدم حساب Twilio التجريبي على أنه خدمة إنتاج مجانية، ولا تعتبر نجاح طلب API دليلاً على وصول الرسالة. الدليل هو وصول SMS فعلياً إلى الهاتف.

## 3. فحص كلمات المرور المسرّبة

أضفت فحصاً إضافياً عند التسجيل وتعيين كلمة مرور جديدة. تُحسب بصمة SHA-1 داخل المتصفح ويُرسل أول خمسة أحرف سداسية فقط إلى واجهة Pwned Passwords، وفق تقنية k-anonymity.

- [توثيق Have I Been Pwned الرسمي](https://haveibeenpwned.com/API/v3#PwnedPasswords)

هذا فحص مجاني إضافي وليس حماية خادمية مكافئة لحماية Supabase المدمجة، لأنه يمكن تجاوز كود المتصفح باستدعاء API مباشرة. لذلك يجب إبقاء سياسة قوة كلمة المرور في Supabase مفعّلة واستخدام الحماية الخادمية المدمجة عند توفرها في الخطة، أو نقل التحقق إلى خادم مصادقة يمكن فرضه عليه.

## 4. المكالمات الصوتية والمرئية والبث

أضفت إلى MYGRAM Chat أساس مكالمات WebRTC صوتية ومرئية بين شخصين، مع جدول إشارات خاص محمي بسياسات RLS وتنتهي صلاحيته بعد عشر دقائق. لا تُخزَّن وسائط المكالمة في قاعدة البيانات، بل تنتقل مباشرة بين المتصلين.

يستخدم التنفيذ خادم STUN عامّاً لاكتشاف الاتصال. بعض الشبكات تحتاج TURN لترحيل الوسائط، وقد تفشل المكالمة المباشرة من دون TURN. هذا التنفيذ ليس بعدُ بثاً مباشراً جماهيرياً ولا مكالمات جماعية.

للبث والمكالمات الأكثر اعتمادية، يمكن تجربة [خطة LiveKit Cloud المجانية](https://livekit.com/pricing) أو استضافة [خادم LiveKit المفتوح المصدر](https://docs.livekit.io/transport/self-hosting/). تحتاج LiveKit Cloud إلى حساب ومفاتيح سرية؛ لا تُدرج هذه المفاتيح في JavaScript. والخطة المجانية لها حدود استخدام وليست ضماناً بخدمة غير محدودة مجاناً.

## 5. الاختبارات قبل إطلاق عام

- [ ] رسالة تأكيد بريد حقيقية تصل إلى عنوان خارج فريق Supabase.
- [ ] رسالة استعادة كلمة المرور تصل ويعمل رابطها على النطاق المنشور.
- [ ] رمز SMS يصل فعلياً إلى هواتف حقيقية في الدول المدعومة.
- [ ] مكالمة صوتية ومكالمة فيديو بين جهازين حقيقيين وعلى شبكتين مختلفتين.
- [ ] اختبار شبكة تحتاج TURN، ثم إضافة خادم ترحيل قبل الادعاء بأن الاتصال يعمل على كل الشبكات.
- [ ] مراجعة حدود الإرسال وCAPTCHA وRLS وسجلات المزودين قبل فتح التسجيل للجمهور.
