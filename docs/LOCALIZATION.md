# اللغات والدول

## 1. الحالة المقاسة حالياً

| العنصر | Production | Staging |
|---|---:|---:|
| supported_locales | 60 | 60 |
| supported_countries | 205 | 205 |
| translation_catalog | 2,820 | غير موجود |
| مفاتيح الترجمة الأساسية لكل لغة في Production | 47 | غير متوفر |

تؤكد أعداد الصفوف وجود 60 خيار لغة و205 دولة/إقليم في Staging، لكنها لا تثبت اكتمال ترجمة واجهة MYGRAM. جدول الترجمة catalog غير موجود في Staging، وواجهة React الحالية ما زالت تعرض النصوص العربية مباشرة. لذلك لا نعلن دعم 60 لغة كاملاً.

في Production يوجد 2,820 سجل ترجمة approved، أي 47 مفتاحاً لكل لغة من 60 لغة عند آخر جرد. هذا أيضاً لا يثبت تغطية كل شاشة أو رسالة خطأ أو تسمية وصول.

## 2. معيار ملفات الترجمة

- كل لغة لها ملف موارد مستقل.
- المفاتيح ثابتة وغير مرتبطة بنص المصدر.
- لا تختلط العربية والإنجليزية والفرنسية داخل الواجهة نفسها إلا في أسماء العلامات التجارية أو النصوص التي يكتبها المستخدم.
- العربية وUrdu وPersian وHebrew وPashto تستخدم RTL وفق metadata اللغة.
- بقية اللغات تستخدم LTR ما لم تثبت metadata خلاف ذلك.
- لا يستخدم fallback لتغطية نقص الترجمة بصمت في اختبارات القبول.
- يحفظ المستخدم اختياره وتستعاد اللغة قبل رسم المكونات.
- أسماء العلامات التجارية وأسماء المنتجات تبقى كما هي وفق دليل الهوية.

## 3. نطاق التغطية المطلوب

يجب أن يشمل جرد المفاتيح:
- جميع قوائم التنقل والمنتجات التسعة.
- الأزرار وعناصر التحكم والنماذج.
- التسجيل والدخول واستكمال الملف والتحقق.
- المنشورات والتعليقات والتفاعلات والقصص.
- الرسائل والمكالمات والاجتماعات.
- الفيديو والرفع والتخزين.
- المحفظة والخدمات المالية.
- حالات Loading وEmpty وError وSuccess وOffline.
- رسائل التحقق والقيود الأمنية.
- Accessibility labels وARIA.
- الإشعارات ورسائل البريد وقوالب النظام.

## 4. الدول وأرقام الهاتف

يوجد 205 صفوف في supported_countries على Staging وProduction. قبل اعتبار التسجيل الدولي مكتملاً يجب التحقق من:
- ISO country code وصحة الاسم العربي والإنجليزي.
- رمز الاتصال الدولي.
- إمكانية مشاركة رمز الاتصال بين دول مختلفة.
- الصيغة الوطنية والبادئة الوطنية عند وجودها.
- التحقق باستخدام مكتبة metadata محدثة مثل libphonenumber.
- تنسيق E.164 قبل إرسال الطلب إلى Supabase.
- عدم استنتاج الجنسية من الموقع الجغرافي أو رقم الهاتف.
- فصل الجنسية عن بلد الإقامة ورمز اتصال الهاتف.

Phone Auth وOTP ومزود SMS غير منفذين بعد؛ وجود رمز الاتصال في القائمة لا يعني تفعيل استقبال OTP.

## 5. خدمة الترجمة الديناميكية

توجد في Staging بنيتا ui_translation_cache وui_translation_daily_usage مقفلتان على service_role وبحد يومي محافظ 4,500 حرف. لكن لا توجد Edge Function ترجمة منشورة حالياً، ولا يجوز اعتبار البنية وحدها خدمة عاملة أو بديلاً عن ترجمة الواجهات الثابتة.

يجب عدم إرسال رسائل المستخدمين أو الملفات الشخصية أو أي بيانات خاصة إلى مزود ترجمة خارجي. تقتصر الترجمة الديناميكية على النصوص العامة المسموح بها بعد مراجعة الخصوصية.

## 6. اختبارات الترجمة

- كل مفتاح واجهة مطلوب موجود في 60 ملف موارد.
- لا تظهر مفاتيح خام للمستخدم.
- لا يوجد خلط غير مقصود بين لغات مختلفة.
- RTL/LTR صحيحان على الهاتف والحاسوب.
- الأسماء الطويلة والرسائل الطويلة لا تكسر التصميم.
- تُراجع الترجمة البشرية للمصطلحات الحساسة والمالية والأمنية.
- الاختبارات تفشل عند نقص أي مفتاح، ولا تسمح fallback صامتاً.
