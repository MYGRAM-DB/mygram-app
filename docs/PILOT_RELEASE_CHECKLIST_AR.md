# قائمة قبول نسخة MYGRAM التجريبية

هذه القائمة هي بوابة الإصدار. ظهور زر أو نجاح اختبار واجهة لا يثبت وحده نجاح خدمة الاتصالات الفعلية.

## أ. بوابة البناء والنشر
- [ ] أحدث تشغيل GitHub Actions ينجح في كل اختبارات Playwright على Chromium desktop وmobile.
- [ ] فحص JavaScript syntax ينجح لكل ملفات JS.
- [ ] ملف المصدر المضغوط يشمل صفحات الاجتماعات وWHATSMYGRAM، ملفات الاتصال والهوية، docs/، supabase/، tests/، package.json وplaywright.config.js.
- [ ] لا يُعتمد أي إصدار إلا بعد نجاح اختبارات CI على commit المقصود، ثم نجاح مهمة Deploy verified site to GitHub Pages من main. دمج النسخة التجريبية الأساسية تم في 26 أكتوبر 2026؛ افحص أحدث تشغيل ولا تعتمد أرقام PR قديمة.
- [ ] تجربة الوصول إلى جميع الصفحات من روابط التنقل الجديدة، خصوصاً على عرض هاتف صغير.

## حالة الإصدار عند تحديث هذه القائمة
- النسخة التجريبية المتكاملة مدمجة في main. نجح نشر الإصدار الأساسي، مع 140 اختباراً آلياً ناجحاً في تشغيل التحقق قبل الدمج.
- مزودات Google وSMS وSMTP وTURN وLiveKit وAI ما زالت بوابة منفصلة: لا تعتبر مكتملة قبل ضبط الأسرار واختبارات الأجهزة الفعلية.

## ب. الواجهة والهوية
- [ ] تطابق شعار MYGRAM مع التدرج السماوي/النيلي/البنفسجي وظهور نسختي light/inverse بشكل مقروء.
- [ ] التأكد من عدم وجود مناطق نقر متراكبة في حفظ الملف الشخصي، التغذية، الرسائل أو أزرار الاتصال.
- [ ] تجربة RTL العربية وLTR الإنجليزية، وتدفق التنقل بين Messenger وMYGRAM Chat وWHATSMYGRAM وMeetings.
- [ ] اختبار كتم الأصوات وتفعيلها بعد أول تفاعل من المستخدم.

## ج. الحسابات والبريد
- [ ] إنشاء حساب جديد ببريد اختباري وتأكيد وصول البريد فعلياً.
- [ ] إعادة ضبط كلمة المرور وفتح الرابط الصحيح والاحتفاظ بالجلسة بعد التحديث.
- [ ] Google OAuth عبر Supabase callback والعودة إلى GitHub Pages، بما في ذلك الرفض ورسالة الخطأ.
- [ ] رسائل SMTP من نطاق موثّق والتحقق من SPF/DKIM وسجلات التسليم.

## د. SMS/OTP
- [ ] تفعيل Phone Auth وربط مزود SMS في Supabase.
- [ ] اختبار وصول OTP إلى أرقام حقيقية في بلدين على الأقل وبصيغة E.164.
- [ ] اختبار OTP خاطئ/منتهي، إعادة الإرسال، حدود المعدل، ورقم غير مدعوم.
- [ ] التأكد من تسجيل التسليم في لوحة المزود، لا الاكتفاء برسالة نجاح من الواجهة.

## هـ. مكالمات فردية
- [ ] اتصال صوتي من جهاز إلى جهاز داخل MYGRAM Chat.
- [ ] اتصال فيديو من جهاز إلى جهاز داخل MYGRAM Chat.
- [ ] الاتصال الفردي من تبويب Messenger لا يظهر إلا بعد وجود محادثة حقيقية بين الطرفين.
- [ ] الاتصال الفردي في WHATSMYGRAM يعمل على جدول الإشارات المنفصل ولا يخلط الرسائل بين المنتجين.
- [ ] اختبار أذونات الميكروفون/الكاميرا، الرفض، القبول، الإنهاء والانقطاع.
- [ ] تجربة شبكتين مختلفتين مع TURN حقيقي، ثم شبكة هاتف خلوي.
- [ ] لا يُعلن دعم مكالمات المجموعات في Messenger/WHATSMYGRAM لأنها غير مفعلة حالياً.

## و. Meetings
- [ ] إنشاء اجتماع من حساب المضيف والانضمام من حسابين آخرين عبر رابط الدعوة.
- [ ] التحقق من سقف 31 مشاركاً إجمالاً، ونقل الرئاسة وسجل التدقيق.
- [ ] اختبار الموافقة الصريحة لكل حاضر وسحب الموافقة قبل تخزين أي نص إضافي.
- [ ] إعداد LiveKit والتحقق من audio/video join وcamera/microphone controls.
- [ ] إعداد مزود AI، واختبار محضر عربي وإنجليزي وصيني/هندي على محتوى تجريبي غير حساس، ومراجعة عدم اختلاق قرارات.
- [ ] تجربة PDF من المتصفح. الإرسال الآلي بالبريد والتخزين الدائم لملف PDF ليسا في النطاق الحالي.

## ز. أمان وتكلفة
- [ ] مراجعة تنبيهات Supabase Security Advisors، بما فيها تعطيل leaked-password protection ومراجعة صلاحيات SECURITY DEFINER RPCs.
- [ ] التأكد من عدم وجود Service Role أو OAuth/SMS/SMTP/TURN/LiveKit/AI secrets في GitHub أو JavaScript.
- [ ] تفعيل حدود إنفاق وتنبيهات لدى مزود SMS وTURN وLiveKit وAI.
- [ ] مراجعة سياسات RLS لجميع الجداول الجديدة واختبار عدم وصول مستخدم إلى سجل مستخدم آخر.
- [ ] تصدير سجلات اختبار بدون بيانات شخصية وتسجيل التكلفة الفعلية لكل تجربة.

## أسرار مطلوبة قبل بدء اختبار المزودات
- Google: OAuth Client ID وClient Secret في إعدادات Supabase Auth.
- SMS: بيانات مزود OTP في Phone Auth settings.
- البريد: SMTP Host/Port/Username/Password ومرسل موثّق.
- TURN: CLOUDFLARE_TURN_KEY_ID وCLOUDFLARE_TURN_KEY.
- اجتماعات LiveKit: LIVEKIT_URL وLIVEKIT_API_KEY وLIVEKIT_API_SECRET.
- ملخصات الذكاء الاصطناعي: MYGRAM_MEETING_AI_API_URL وMYGRAM_MEETING_AI_API_KEY وMYGRAM_MEETING_AI_MODEL.

لا ترسل أي سرّ في المحادثة أو في GitHub. ضع كل قيمة سرية مباشرة في لوحة مزودها أو Supabase Edge Function Secrets، ثم نفّذ الاختبارات أعلاه.
