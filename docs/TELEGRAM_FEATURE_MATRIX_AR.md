# مصفوفة ميزات تيليجرام وخطة دمجها في MYGRAM

هذا الملف يميّز بين ما أُضيف إلى فرع التطوير، وما يحتاج إعداد خدمة أو اختبار إنتاج، وما يبقى ضمن خارطة الطريق. وجود واجهة أو جدول لا يعني أن الميزة منشورة أو مكتملة من طرف إلى طرف.

## المنتجات التي تبقى منفصلة

| المساحة | الغرض |
|---|---|
| MYGRAM Messenger | المراسلة المباشرة، الملف الشخصي والحضور، الوسائط والصوت |
| MYGRAM Chat | مساحة محادثات مستقلة، فردية أو جماعية |
| WHATSMYGRAM | منتج مراسلة مستقل بجداول وواجهة ووسائط منفصلة |
| MYGRAM Meetings | اجتماعات عمل/تعليم، حضور ورئاسة ودردشة ومحاضر |

تُشارك المساحات الثلاث الخاصة بالدردشة خدمات أساسية مثل التفاعلات والحفظ والبحث حيثما يناسب نوع المحادثة، دون توحيد هويات المنتجات أو خلط الرسائل والجداول الخاصة بينها.

## الميزات المضافة إلى فرع التطوير

- واجهة محادثات متجاوبة، مؤشرات الحضور مع خيار إخفاء الحالة، ورسائل صوتية داخل فقاعات مع المدة ومشغل، وحد تسجيل صوتي عشر دقائق.
- أدوات مشتركة داخل المحادثات: بحث، مواضيع للمجموعات مع فلترة رسائل الموضوع، تثبيت للمشرفين/المنشئ، محفوظات شخصية، استطلاعات وتصويت، وردّ مرتبط برسالة أصلية.
- تفاعلات إيموجي على رسائل المحادثات مع العدّادات، وتغذية صوتية لأحداث مثل الرسالة والتفاعل والتنبيه، مع إمكانية كتم الصوت.
- مكالمات صوت وفيديو فردية عبر WebRTC في MYGRAM Chat وMessenger المباشر وWHATSMYGRAM، مع جداول إشارات خاصة بسياسات RLS؛ الاتصال المباشر يتطلب وجود رسالة سابقة بين الطرفين. مكالمات المجموعات غير مفعلة في هذه المساحات.
- WHATSMYGRAM مستقل في الجداول والواجهة، مع محادثات ووسائط ودعم رسائل صوتية.
- Meetings: إنشاء اجتماع ودعوات برمز، حد أقصى 31 شخصاً إجمالاً (المضيف ضمن العدد)، أعضاء وأدوار، نقل الرئاسة مع سجل تدقيق، دردشة نصية، طلب موافقة الحضور قبل حفظ النص، ومحاضر لكل مشارك حسب اللغة المفضلة.
- تصدير المحضر من واجهة Unicode إلى نافذة الطباعة وحفظ PDF من المتصفح. المحاضر المخزنة محمية بسياسة وصول شخصية.
- هوية MYGRAM البصرية: علامة سوداء مع شيفرونات خضراء وحمراء، wordmark أفقي فاتح/داكن، وألوان موحدة مرتبطة بعناصر التنقل والحالات وأزرار التفاعل والاجتماعات.

## قاعدة البيانات والأمان

- هجرات إضافية لا تحذف الرسائل أو المستخدمين: حالة الحضور، مساحة WHATSMYGRAM، أدوات المحادثة، الاجتماعات، موافقات النصوص، سجل نقل الرئاسة، والتفاعلات.
- تم تفعيل Row Level Security على الجداول الجديدة الخاصة بالأدوات والاجتماعات والتفاعلات وإشارات مكالمات WHATSMYGRAM، والتحقق من تفعيلها في قاعدة البيانات.
- تحقق قواعد البيانات أن الرسالة المثبتة أو المتفاعل معها تنتمي فعلاً للمحادثة المعنية، وأن تفاعل الرسالة المباشرة لا يصدر إلا عن أحد طرفيها.
- دوال Edge الخاصة بتوكن الفيديو ومحاضر الذكاء الاصطناعي تتحقق من جلسة المستخدم والصلاحيات، ولا تضع مفاتيح الخادم داخل JavaScript المتصفح.

## إعدادات خارجية مطلوبة قبل استخدام الخدمات الحية

- فيديو الاجتماعات: أسرار Supabase Edge Function باسم LIVEKIT_URL وLIVEKIT_API_KEY وLIVEKIT_API_SECRET. من دونها تعرض الواجهة خطأ إعداد واضحاً.
- المحاضر الذكية: MYGRAM_MEETING_AI_API_URL وMYGRAM_MEETING_AI_API_KEY وMYGRAM_MEETING_AI_MODEL (أو مفاتيح الترجمة البديلة الموجودة في الدالة). هذه الخدمة قد تحمل تكلفة؛ لا نفترض أنها مجانية.
- تحويل الكلام إلى نص الموجود في الواجهة يعتمد على SpeechRecognition في متصفح المشارك وعلى ميكروفونه المحلي. هو نموذج أولي، وليس نظاماً يستمع إلى صوت جميع المشاركين عبر خادم ويعرّف كل متحدث.
- PDF يُنشأ حالياً من نافذة الطباعة في جهاز المشارك. الإرسال الآلي بالبريد، تخزين ملف PDF جاهز في Storage، والتوزيع الآلي خارج التطبيق لم تُنفذ بعد.
- يجب اختبار اجتماع من عدة حسابات، صلاحية نقل الرئاسة، موافقة التسجيل، فيديو حقيقي، وجودة ملخصات كل لغة قبل إعلانها متاحة للإنتاج.

## ميزات تيليجرام المميزة التي لا ينبغي الادعاء بأنها مكتملة بعد

| الميزة | الحالة |
|---|---|
| قنوات عامة واكتشاف/اشتراك وبث أحادي الاتجاه | هناك أساس بيانات للأدوار والمساحات العامة، لكن تدفق إنشاء القناة واكتشافها والاشتراك بها لم يكتمل |
| المنتديات ومواضيع قابلة للإدارة داخل المجموعات | أساس المواضيع وفلترتها موجود؛ إدارة المنتدى الكاملة وإشعارات كل موضوع لم تكتمل |
| Bots وMini Apps وواجهات الأتمتة | لم تُنفذ |
| Secret Chats بتشفير طرف لطرف ومفاتيح وتحقق من الطرفين | لم تُنفذ. لا تصف الدردشة الحالية بأنها E2E مشفرة |
| جدولة الرسائل، رسائل ذاتية الاختفاء، تعديل/حذف متقدم وسجل تعديلات | لم تكتمل كحزمة موحدة |
| بث صوتي/فيديو جماعي واسع وقنوات ذات جمهور كبير | خارج نطاق التحقق الحالي |
| ترجمة فورية لكل الرسائل والمحادثات، مع فصل اللغة المختارة لكل مستخدم | لا تزال بحاجة إلى تنفيذ واختبار؛ قائمة 60 لغة لا تعني ترجمة كل شاشة |
| إرسال البريد التلقائي لمحاضر الاجتماعات | غير منفذ؛ المحضر يظهر في الحساب ويُصدّر يدوياً إلى PDF |

## بوابة الإصدار

لا يُدمج فرع التطوير في main إلا بعد نجاح CI على آخر تعديل ومراجعة اختلافه عن main. بعد الدمج يجب التأكد من نجاح GitHub Pages، ثم تجربة تسجيل الدخول والتنقل على الهاتف والحاسوب. لا يُعلن اكتمال مكالمات الفيديو أو تلخيص AI قبل إضافة أسرارهما واختبارهما فعلياً.
